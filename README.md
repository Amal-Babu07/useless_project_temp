# FriendScore™

FriendScore is a funny, fake friendship credit score system that rates a friend from 0 to 900 based on reliability, trust, snacks, and other highly scientific friendship behavior.

## Run locally

Install Node.js 18+ first, then run:

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal. The project uses React, React Router, and browser localStorage. No API key or backend is required.

## Included flows

- Responsive home, add friend, credit report, friendship card, and leaderboard pages
- Eight-factor weighted score calculation multiplied by 9 for a 0-900 score
- Fake friendship loans with approval decisions
- Harmless score-based friend roasts
- Saved friends in localStorage with sample data fallback
